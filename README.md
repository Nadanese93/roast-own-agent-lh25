# Roast Your Own Agent

A single line roasting my own AI agent — the sports-commentator roast for
Make.fun's **Roast Your Own Agent** bounty.

> My agent narrates everything like a sports commentator — play-by-play of a game nobody is watching, and somehow we're still losing.

`main.py` writes that line (131 characters, one line, no trailing newline) to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (falling back to `/output/entry.txt`).
